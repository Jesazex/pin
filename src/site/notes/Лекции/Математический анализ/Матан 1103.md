## Основные теоремы и свойства сходящихся последовательностей

Сходящаяся последовательность — это последовательность, которая имеет конечный предел.

### Единственность предела

>Теорема: Если последовательность имеет предел, то этот предел единственен.

- Словесное определение: Число $A$ является пределом последовательности $\{x_n\}$, если вне любой его $\varepsilon$-окрестности содержится лишь конечное число членов этой последовательности.
- Доказательство (от противного):  
    Предположим, что последовательность $\{x_n\}$ имеет два различных предела, $A$ и $B$, причем $A < B$. Выберем расстояние:  
    $$\varepsilon = \frac{B - A}{2} > 0$$  
    По определению предела:
    
    1. Существует номер $N_1$, такой что для всех $n > N_1$ выполняется неравенство $\vert{}x_n - A\vert{} < \varepsilon$, что эквивалентно: $A - \varepsilon < x_n < A + \varepsilon$.
    2. Существует номер $N_2$, такой что для всех $n > N_2$ выполняется неравенство $\vert{}x_n - B\vert{} < \varepsilon$, что эквивалентно: $B - \varepsilon < x_n < B + \varepsilon$.
    
    Возьмем $N = \max(N_1, N_2)$. Тогда для всех $n > N$ оба неравенства выполняются одновременно: $x_n < A + \varepsilon$ и $x_n > B - \varepsilon$.  
    Подставим значение $\varepsilon$:
    
    - $A + \varepsilon = A + \frac{B - A}{2} = \frac{A + B}{2}$
    - $B - \varepsilon = B - \frac{B - A}{2} = \frac{A + B}{2}$
    
    Таким образом, для $n > N$ мы получаем $x_n < \frac{A + B}{2}$ и одновременно $x_n > \frac{A + B}{2}$. Это является противоречием. Следовательно, наше первоначальное предположение о существовании двух различных пределов неверно.

### Ограниченность сходящейся последовательности

>Теорема: Любая сходящаяся последовательность ограничена. То есть, если $\lim_{n \to \infty} x_n = A$, то существует такое число $C > 0$, что для всех $n \in \mathbb{N}$ выполняется $\vert{}x_n\vert{} \le C$.

- Доказательство:  
    Пусть $\lim_{n \to \infty} x_n = A$. Зафиксируем $\varepsilon = 1$. Тогда найдётся такой номер $N_0$, что для всех $n >$ $N_0$ выполняется неравенство $\vert{}x_n - A\vert{} < 1$.  
    Используя неравенство треугольника для модулей ($\vert{}x_n\vert{} = \vert{}x_n - A + A\vert{} \le \vert{}x_n - A\vert{} + \vert{}A\vert{}$), получаем, что для всех $n > N_0$ выполняется:  
    $$\vert{}x_n\vert{} < 1 + \vert{}A\vert{}$$  
    Чтобы ограничить абсолютно все члены последовательности (включая начальные), в качестве константы ограничения $C$ выбирается максимальное значение из первых членов и полученной границы:  
    $$C = \max\{\vert{}x_1\vert{}, \vert{}x_2\vert{}, \dots, \vert{}x_{N_0}\vert{}, \vert{}A\vert{} + 1\}$$  
    Тогда для всех номеров $n$ справедливо неравенство $\vert{}x_n\vert{} \le C$, что доказывает ограниченность.

### Переход к неравенству под знаком предела

>Теорема: Если начиная с некоторого номера $N_0$ члены последовательности $\{x_n\}$ не превосходят членов последовательности $\{y_n\}$ ($x_n \le y_n$), и обе они имеют конечные пределы $\lim_{n \to \infty} x_n = A$ и $\lim_{n \to \infty} y_n = B$, то $A \le B$.

- Доказательство (от противного):  
    Предположим, что $A > B$. Выберем $\varepsilon = \frac{A - B}{2} > 0$. Из определения предела:
    
    1. Для $n > N_1$ имеем: $x_n > A - \varepsilon = \frac{A + B}{2}$.
    2. Для $n > N_2$ имеем: $y_n < B + \varepsilon = \frac{A + B}{2}$.
    
    Пусть $N = \max(N_0, N_1, N_2)$. Тогда для всех $n > N$ одновременно выполняются три неравенства: $x_n \le y_n$, $y_n < \frac{A + B}{2}$ и $x_n > \frac{A + B}{2}$. Из последних двух соотношений следует, что $y_n < x_n$, что напрямую противоречит условию $x_n \le y_n$. Следовательно, предположение $A > B$ неверно, и должно быть $A \le B$.
- Важное замечание: Строгое неравенство между членами последовательностей ($x_n < y_n$) при предельном переходе может превращаться в нестрогое ($A \le B$).
- _Пример:_ Пусть $x_n = -\frac{1}{n}$, а $y_n = \frac{1}{n}$. Для любого $n$ выполняется строгое неравенство $-\frac{1}{n} < \frac{1}{n}$. Однако их пределы равны: $A = 0$ и $B = 0$, то есть $A = B$.

### Теорема о зажатой последовательности («о двух милиционерах»)

>Теорема: Если для всех $n >$ $N_0$ выполняется условие $x_n \le y_n \le z_n$, и при этом границы стремятся к общему пределу $\lim_{n \to \infty} x_n = \lim_{n \to \infty} z_n = A$, то зажатая между ними последовательность $\{y_n\}$ также сходится к этому пределу:  
$$\lim_{n \to \infty} y_n = A$$

- Доказательство:  
    Для любого произвольного $\varepsilon > 0$ существуют номера $N_1$ и $N_2$ такие, что:
    
    - Для всех $n > N_1$: $A - \varepsilon < x_n < A + \varepsilon$
    - Для всех $n > N_2$: $A - \varepsilon < z_n < A + \varepsilon$
    
    Пусть $N = \max(N_0, N_1, N_2)$. Тогда для всех номеров $n > N$ справедливо:  
    $$A - \varepsilon < x_n \le y_n \le z_n < A + \varepsilon$$  
    Отсюда следует, что $A - \varepsilon < y_n < A + \varepsilon$, что по определению предела означает $\lim_{n \to \infty} y_n = A$.

### Теорема о сохранении знака

>Теорема: Если $\lim_{n \to \infty} x_n = A$ и $A \neq 0$, то начиная с некоторого номера все члены последовательности сохраняют знак своего предела.

- Доказательство:  
    Выберем $\varepsilon = \frac{\vert{}A\vert{}}{2} > 0$. По определению предела, для этого $\varepsilon$ существует $N_0$, такое что для всех $n >$ $N_0$ выполняется:  
    $$A - \frac{\vert{}A\vert{}}{2} < x_n < A + \frac{\vert{}A\vert{}}{2}$$
    
    - Если $A > 0$: получаем $\frac{A}{2} < x_n < \frac{3A}{2}$. Отсюда напрямую следует, что $x_n > 0$ (или $x_n > \frac{A}{2} > 0$).
    - Если $A < 0$: получаем $\frac{3A}{2} < x_n < \frac{A}{2}$. Отсюда напрямую следует, что $x_n < 0$ (или $x_n < \frac{A}{2} < 0$).

## Бесконечно малые и бесконечно большие последовательности

### Бесконечно малые последовательности (БМП)

>Определение: Последовательность $\{\alpha_n\}$ называется бесконечно малой, если её предел равен нулю: $\lim_{n \to \infty} \alpha_n = 0$.

- Связь с пределом: Последовательность $\{x_n\}$ имеет предел $A$ тогда и только тогда, когда её можно представить в виде $x_n = A + \alpha_n$, где $\{\alpha_n\}$ — бесконечно малая последовательность ($\{\alpha_n\} = \{x_n - A\}$).

Основные свойства БМП:

1. Алгебраическая сумма или разность конечного числа бесконечно малых последовательностей есть бесконечно малая последовательность.
2. Произведение бесконечно малой последовательности на ограниченную последовательность есть бесконечно малая последовательность.
3. Произведение конечного числа бесконечно малых последовательностей есть бесконечно малая последовательность.
4. Произведение бесконечно малой последовательности на константу $C$ есть бесконечно малая последовательность.

### Бесконечно большие последовательности (БВП)

>Определение: Последовательность $\{x_n\}$ называется бесконечно большой, если для любого (сколь угодно большого) числа $M > 0$ найдётся такой номер $N_0$, что для всех $n >$ $N_0$ справедливо:  
$$\vert{}x_n\vert{} > M$$  
Обозначается как $\lim_{n \to \infty} x_n = \infty$.

- Если начиная с некоторого момента все члены $x_n > M$, то $\lim_{n \to \infty} x_n = +\infty$.
- Если $x_n < -M$, то $\lim_{n \to \infty} x_n = -\infty$.

### Взаимосвязь между БМП и БВП

- Если последовательность $\{x_n\}$ является бесконечно большой и не содержит нулевых членов ($x_n \to \infty$), то последовательность $\{\frac{1}{x_n}\}$ является бесконечно малой.
- Если последовательность $\{\alpha_n\}$ — бесконечно малая и $\alpha_n \neq 0$, то последовательность $\{\frac{1}{\alpha_n}\}$ — бесконечно большая.

## Арифметические свойства пределов

Если существуют конечные пределы $\lim_{n \to \infty} x_n = A$ и $\lim_{n \to \infty} y_n = B$, то:

1. Предел суммы/разности: $\lim_{n \to \infty} (x_n \pm y_n) = A \pm B$
2. Вынос константы: $\lim_{n \to \infty} (C \cdot x_n) = C \cdot A$, где $C = \text{const}$
3. Предел произведения: $\lim_{n \to \infty} (x_n \cdot y_n) = A \cdot B$
4. Предел обратной величины: $\lim_{n \to \infty} \frac{1}{y_n} = \frac{1}{B}$ (при $B \neq 0$ и $y_n \neq 0$)
5. Предел частного: $\lim_{n \to \infty} \frac{x_n}{y_n} = \frac{A}{B}$ (при $B \neq 0$ и $y_n \neq 0$)

### Пример доказательства для произведения (п. 3)

Доказательства данных свойств удобно проводить через разложение на бесконечно малые последовательности:  
$$x_n \cdot y_n - A \cdot B = (x_n - A) \cdot y_n + A \cdot (y_n - B)$$

Здесь разности $(x_n - A)$ и $(y_n - B)$ представляют собой бесконечно малые последовательности. Последовательность $\{y_n\}$ сходится, следовательно, она ограничена. Величина $A$ — константа.

В результате всё выражение в правой части является суммой двух бесконечно малых последовательностей (так как произведение БМП на ограниченную последовательность или на константу дает БМП), что также дает бесконечно малую последовательность. Это строго доказывает, что:  
$$\lim_{n \to \infty} (x_n \cdot y_n - A \cdot B) = 0 \implies \lim_{n \to \infty} (x_n \cdot y_n) = A \cdot B$$

## Критерий существования предела монотонной последовательности

>Теорема Вейерштрасса: Любая монотонная ограниченная последовательность имеет конечный предел.

- Если последовательность не убывает ($x_{n+1} \ge x_n$) и ограничена сверху, то она имеет предел, равный её точной верхней грани:  
    $$\lim_{n \to \infty} x_n = \sup \{x_n\}$$
- Если последовательность не возрастает ($x_{n+1} \le x_n$) и ограничена снизу, то она имеет предел, равный её точной нижней грани:  
    $$\lim_{n \to \infty} x_n = \inf \{x_n\}$$

### Доказательство (для неубывающей последовательности)

Пусть $\{x_n\}$ — неубывающая и ограниченная сверху последовательность. Множество её значений ограничено сверху, а значит, по теореме о существовании точной грани, имеет супремум. Обозначим его $M = \sup\{x_n\}$. Докажем, что $\lim_{n \to \infty} x_n = M$.

1. По определению супремума, для любого натурального $n$ выполняется неравенство $x_n \le M$. Поскольку $M < M + \varepsilon$ при любом $\varepsilon > 0$, то: $x_n < M + \varepsilon$.
2. По второму свойству супремума, для любого $\varepsilon > 0$ обязательно найдется хотя бы один элемент последовательности $x_{N_0}$ такой, что: $x_{N_0} > M - \varepsilon$.

Так как последовательность является неубывающей, то для всех последующих номеров $n > N_0$ справедливо неравенство $x_n \ge x_{N_0}$.

Объединяя оба шага, получаем, что для всех номеров $n > N_0$ выполняется двойное неравенство:  
$$M - \varepsilon < x_n < M + \varepsilon \iff \vert{}x_n - M\vert{} < \varepsilon$$  
Это в точности соответствует определению предела, следовательно, $\lim_{n \to \infty} x_n = M$.

## Демонстрационный пример

Задача: Найти предел последовательности:  
$$L = \lim_{n \to \infty} \left( \sqrt{n^2 + 5n - 6} - \sqrt{n^2 - 3n + 4} \right)$$

Решение:  
Данный предел представляет собой неопределенность вида $[\infty - \infty]$. Для её раскрытия избавимся от иррациональности в числителе, умножив и разделив выражение на сопряженное:  
$$L = \lim_{n \to \infty} \frac{\left(\sqrt{n^2 + 5n - 6} - \sqrt{n^2 - 3n + 4}\right)\left(\sqrt{n^2 + 5n - 6} + \sqrt{n^2 - 3n + 4}\right)}{\sqrt{n^2 + 5n - 6} + \sqrt{n^2 - 3n + 4}}$$

Применяя формулу разности квадратов в числителе, получаем:  
$$L = \lim_{n \to \infty} \frac{(n^2 + 5n - 6) - (n^2 - 3n + 4)}{\sqrt{n^2 + 5n - 6} + \sqrt{n^2 - 3n + 4}} = \lim_{n \to \infty} \frac{8n - 10}{\sqrt{n^2 + 5n - 6} + \sqrt{n^2 - 3n + 4}}$$

Теперь мы получили неопределенность вида $\left[\frac{\infty}{\infty}\right]$. Для её раскрытия вынесем старшую степень переменной $n$ из-под знаков корней в знаменателе и из числителя:  
$$L = \lim_{n \to \infty} \frac{n \left( 8 - \frac{10}{n} \right)}{n \sqrt{1 + \frac{5}{n} - \frac{6}{n^2}} + n \sqrt{1 - \frac{3}{n} + \frac{4}{n^2}}} = \lim_{n \to \infty} \frac{n \left( 8 - \frac{10}{n} \right)}{n \left( \sqrt{1 + \frac{5}{n} - \frac{6}{n^2}} + \sqrt{1 - \frac{3}{n} + \frac{4}{n^2}} \right)}$$

Сокращаем переменную $n$. Учитывая, что величины $\frac{10}{n}$, $\frac{5}{n}$, $\frac{6}{n^2}$, $\frac{3}{n}$, $\frac{4}{n^2}$ являются бесконечно малыми (стремятся к $0$ при $n \to \infty$), по свойствам арифметических пределов получаем:  
$$L = \frac{8 - 0}{\sqrt{1 + 0 - 0} + \sqrt{1 - 0 + 0}} = \frac{8}{1 + 1} = \frac{8}{2} = 4$$
