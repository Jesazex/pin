Тема: Замечательные пределы и критерий Коши

## Первый замечательный предел

Рассматривается поведение тригонометрических функций в окрестности нуля. Из геометрических соображений на единичном круге для малых положительных углов справедлива система неравенств, связывающая синус, длину дуги и тангенс:

$$\sin x < x < \operatorname{tg} x$$

Разделив все части неравенства на $\sin x$ (при условии, что $x \to 0$ и $\sin x > 0$), получаем следующее соотношение:

$$1 < \frac{x}{\sin x} < \frac{1}{\cos x}$$

Переходя к обратным величинам, знаки неравенства меняются на противоположные:

$$\cos x < \frac{\sin x}{x} < 1$$

Так как функция $y = \cos x$ является непрерывной и $\lim_{x \to 0} \cos x = 1$, по теореме о зажатой функции (о двух милиционерах) предел отношения синуса к его аргументу равен единице.

>Первый замечательный предел:
$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

### Следствие из первого замечательного предела

Если функция $\alpha(x)$ является бесконечно малой величиной при $x \to x_{0}$ (то есть $\lim_{x \to x_{0}} \alpha(x) = 0$), то предел их отношения также стремится к единице:
$$\lim_{x \to x_{0}} \frac{\sin \alpha(x)}{\alpha(x)} = 1$$

## Второй замечательный предел

Для доказательства второго замечательного предела сначала рассматривается случай для последовательности и вводится понятие целой части числа. Пусть переменная $x$ стремится к бесконечности ($x \to \infty$). Каждое вещественное число $x$ можно заключить между двумя последовательными целыми числами:

$$[x] \le x < [x] + 1$$

где $[x]$ — целая часть числа $x$. Отсюда вытекает неравенство для обратных величин:

$$\frac{1}{[x] + 1} < \frac{1}{x} \le \frac{1}{[x]}$$

Прибавляя единицу и возводя в соответствующую степень, проводится двусторонняя оценка выражения $\left(1 + \frac{1}{x}\right)^x$:

$$\left(1 + \frac{1}{[x] + 1}\right)^{[x]} < \left(1 + \frac{1}{x}\right)^x < \left(1 + \frac{1}{[x]}\right)^{[x] + 1}$$

Поскольку при $x \to \infty$ целая часть $[x]$ также стремится к бесконечности, обе границы данного неравенства сходятся к числу $e$. На основании этого формулируется фундаментальный предел.

>Второй замечательный предел:
$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$$

Или в эквивалентной форме для бесконечно малой переменной $\alpha \to 0$:
$$\lim_{\alpha \to 0} (1 + \alpha)^{\frac{1}{\alpha}} = e$$

### Следствия из второго замечательного предела

1. **Предел для натурального логарифма**:
   $$\lim_{x \to 0} \frac{\ln(1 + x)}{x} = 1$$
   *Доказательство*: используя свойства логарифма, выражение преобразуется к виду $\ln(1 + x)^{\frac{1}{x}}$. Так как предел функции под знаком логарифма равен $e$, получаем $\ln e = 1$.

2. **Предел для общего логарифма по основанию $a$**:
   $$\lim_{x \to 0} \frac{\log_{a}(1 + x)}{x} = \frac{1}{\ln a} = \log_{a} e$$

3. **Предел для показательной функции**:
   $$\lim_{x \to 0} \frac{a^x - 1}{x} = \ln a$$
   При $a = e$ предел принимает вид:
   $$\lim_{x \to 0} \frac{e^x - 1}{x} = 1$$

4. **Предел для степенно-показательной функции**:
   $$\lim_{x \to 0} \frac{(1 + x)^\mu - 1}{x} = \mu$$

## Критерий Коши существования предела

Критерий Коши позволяет установить факт существования предела последовательности или функции без предварительного нахождения самого значения этого предела.


### Критерий Коши для последовательности

Последовательность $x_{n}$ имеет конечный предел тогда и только тогда, когда она является фундаментальной. Это означает, что для любого сколь угодно малого фиксированного числа $\varepsilon > 0$ найдется такой номер $N$, что для всех номеров $n > N$ и $m > N$ выполняется условие:

$$\vert{}x_{n} - x_{m}\vert{} < \varepsilon$$

### Критерий Коши для функции (в терминах непрерывности)

Функция $f(x)$ имеет конечный предел в точке $x_{0}$ тогда и только тогда, когда для любого $\varepsilon > 0$ существует такая окрестность $\delta > 0$, что для любых двух точек $x_{1}$ и $x_{2}$ из этой окрестности ($0 < \vert{}x_{1} - x_{0}\vert{} < \delta$ и $0 < \vert{}x_{2} - x_{0}\vert{} < \delta$) разность значений функции в этих точках удовлетворяет условию:

$$\vert{}f(x_{1}) - f(x_{2})\vert{} < \varepsilon$$

## Связь предела последовательности и предела функции

Для строгого доказательства эквивалентности различных подходов к определению предела используется связь между предельным поведением непрерывного аргумента и дискретных подпоследовательностей.

Если для любой последовательности точек $x_{n}$, сходящейся к числу $A$ ($x_{n} \to A$), соответствующая последовательность значений функций $f(x_{n})$ сходится к числу $B$ ($f(x_{n}) \to B$), то предел функции в данной точке равен $B$:

$$\lim_{x \to A} f(x) = B$$

Данный переход позволяет переносить алгебраические свойства четырех математических действий (сложение, вычитание, умножение и деление), доказанные для пределов последовательностей, на пределы непрерывных функций.
