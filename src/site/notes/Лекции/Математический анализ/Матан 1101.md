## Элементы математической логики

В курсе математического анализа используется символьная (логическая) запись теорем для сокращения объема и структурирования рассуждений.

### Основные кванторы

- Квантор всеобщности: $\forall$ (читается как «для любого», «для каждого»).
- Квантор существования: $\exists$ (читается как «существует», «найдется»).

_Примечание:_ Использование двоеточия после квантора существования ($\exists x : \dots$) является лишь вспомогательным элементом записи, но не строгим логическим символом.

### Логическая структура теорем

Большинство математических утверждений и теорем формулируются в виде импликации (условного высказывания):  
$$\forall x \, (A(x) \implies B(x))$$  
_Пример (Теорема Пифагора):_ $\forall$ треугольника $x$, если $x$ является прямоугольным ($A$), то сумма квадратов его катетов равна квадрату гипотенузы ($B$).

### Построение отрицаний

Для доказательства утверждений методом от противного необходимо уметь строить отрицание к сложным высказываниям. При построении отрицания кванторы меняются на противоположные ($\forall$ переходит в $\exists$, и наоборот), а знак итогового утверждения инвертируется.

Отрицание импликации $A \implies B$ логически эквивалентно конъюнкции $A \land \neg B$ (условие $A$ выполняется, но следствие $B$ не наступает):  
$$\neg(\forall x \, (A(x) \implies B(x))) \iff \exists x \, (A(x) \land \neg B(x))$$

_Пример ложного утверждения:_ $\forall x \in \mathbb{N} \, (x \text{ делится на } 3 \implies x \text{ делится на } 6)$.  
_Его отрицание (истинное):_ $\exists x \in \mathbb{N} \, (x \text{ делится на } 3 \land x \text{ не делится на } 6)$. Контрпример: $x = 3$.

### Принцип полной дизъюнкции

Метод доказательства, при котором рассматривается полный набор несовместимых гипотез $A_1, A_2, \dots, A_n$, в сумме дающих истину ($A_1 \lor A_2 \lor \dots \lor A_n \equiv 1$). Если доказывается ложность всех вариантов, кроме одного, то оставшийся вариант признается истинным.

## Числовые множества и их границы

Пусть $X$ — непустое подмножество множества действительных чисел ($X \subset \mathbb{R}$).

### Ограниченность множеств

- Ограниченное сверху: Множество $X$ называется ограниченным сверху, если существует такое число $a \in \mathbb{R}$ (верхняя грань), что для всех его элементов выполняется неравенство:  
    $$\forall x \in X \implies x \le a$$
- Ограниченное снизу: Множество $X$ называется ограниченным снизу, если существует такое число $b \in \mathbb{R}$ (нижняя грань), что для всех его элементов выполняется неравенство:  
    $$\forall x \in X \implies x \ge b$$
- Ограниченное множество: Множество, ограниченное одновременно и сверху, и снизу. Альтернативное определение через абсолютную величину:  
    $$\exists C > 0 : \forall x \in X \implies \vert{}x\vert{} \le C$$  
    Оба определения эквивалентны. В качестве $C$ можно выбрать значение $\max(\vert{}a\vert{}, \vert{}b\vert{})$.

### Отрицание ограниченности (Неограниченное множество)

Множество $X$ является неограниченным, если для любого, соизмеримо большого числа $C$ найдется элемент, превосходящий его по модулю:  
$$\forall C > 0 \, \exists x \in X : \vert{}x\vert{} > C$$

### Множества граней

Если у множества существует одна верхняя (или нижняя) грань, то любое число, большее (или меньшее) нее, также будет являться гранью. Таким образом, множество граней либо пусто, либо содержит бесконечно много элементов.

_Пример:_ Для полуинтервала $(0, 1]$:

- Множество нижних граней: $(-\infty, 0]$.
- Множество верхних граней: $[1, +\infty)$.
- Число $0$ является наибольшей нижней гранью, число $1$ — наименьшей верхней гранью.

## Точные грани множества

### Точная верхняя грань (Супремум)

Число $M = \sup X$ называется точной верхней гранью множества $X$, если оно является наименьшей из всех его верхних граней.

Математическое определение состоит из двух пунктов:

1. $M$ — одна из верхних граней множества $X$:  
    $$\forall x \in X \implies x \le M$$
2. Любое число, меньшее $M$ (например, $M' < M$ или $M - \varepsilon$), уже не является верхней гранью множества $X$ (то есть в множестве $X$ найдется элемент, который строго больше этого числа):  
    $$\forall \varepsilon > 0 \, \exists x \in X : x > M - \varepsilon$$

### Точная нижняя грань (Инфимум)

Число $m = \inf X$ называется точной нижней гранью множества $X$, если оно является наибольшей из всех его нижних граней.

Математическое определение:

1. $m$ — одна из нижних граней множества $X$:  
    $$\forall x \in X \implies x \ge m$$
2. Любое число, большее $m$ (например, $m' > m$ или $m + \varepsilon$), уже не является нижней гранью множества $X$:  
    $$\forall \varepsilon > 0 \, \exists x \in X : x < m + \varepsilon$$

### Различие между точными гранями и максимумом/минимумом

- Если точная верхняя грань принадлежит самому множеству ($\sup X \in X$), она совпадает с максимальным элементом множества ($\max X$).
- Если точная нижняя грань принадлежит самому множеству ($\inf X \in X$), она совпадает с минимальным элементом множества ($\min X$).
- Точные грани подмножества вещественных чисел существуют всегда (если множество ограничено), в то время как максимального или минимального элементов у множества может не быть.

|Множество $X$|$\inf X$|$\sup X$|$\min X$|$\max X$|
|---|---|---|---|---|
|Отрезок $[0, 1]$|$0$|$1$|$0$|$1$|
|Полуинтервал $(0, 1]$|$0$|$1$|Не существует|$1$|
|Интервал $(0, 1)$|$0$|$1$|Не существует|Не существует|
|$x \in \mathbb{Q} : x^2 \le 5$|$-\sqrt{5}$|$\sqrt{5}$|Не существует|Не существует|

_Примечание к последней строке таблицы:_ Так как границы $-\sqrt{5}$ и $\sqrt{5}$ являются иррациональными числами, они не принадлежат заданному множеству рациональных чисел $\mathbb{Q}$, следовательно, минимума и максимума у этого множества нет.

### Специфика пустого множества $\emptyset$

С точки зрения формальной логики, для пустого множества условие $\forall x \in \emptyset \implies x \le a$ всегда является истинным, так как посылка $x \in \emptyset$ всегда ложна (из лжи следует все что угодно). Поэтому любое действительное число является одновременно и верхней, и нижней гранью для $\emptyset$. Из-за этого точных границ $\sup \emptyset$ и $\inf \emptyset$ в рамках множества действительных чисел не существует.

## Свойства точных граней

Для ограниченных непустых множеств справедливы следующие утверждения:

### Смена знака множества
Если рассмотреть множество $-X = \{ -x \mid x \in X \}$, то его точные грани меняются местами с инверсией знака:

- $\sup(-X) = -\inf X$
- $\inf(-X) = -\sup X$

### Сумма множеств
Суммой двух множеств $X$ и $Y$ называется множество всевозможных попарных сумм их элементов: $X + Y = \{ x + y \mid x \in X, y \in Y \}$.

- $\sup(X + Y) = \sup X + \sup Y$
- $\inf(X + Y) = \inf X + \inf Y$

### Вложение множеств
Если множество $X$ является подмножеством множества $Y$ ($X \subset Y$), то его точные грани ограничены точными гранями более широкого множества:

- $\inf Y \le \inf X \le \sup X \le \sup Y$
