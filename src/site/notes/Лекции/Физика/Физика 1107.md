Тема: Колебательные процессы в физике

## Базовое определение

Колебательный процесс — это процесс, при котором та или иная величина через определенные промежутки времени повторяется точно или приблизительно. Колебаться могут как механические величины (смещение, скорость), так и нефизические или электрические параметры (ток, напряжение, заряд).

---

## Гармонические колебания

Гармонические колебания происходят по закону синуса или косинуса. При решении задач анализ начинают со второго закона Ньютона для поступательного или вращательного движения, после чего составляют однородное дифференциальное уравнение второго порядка.

### Уравнение движения гармонического осциллятора

Для незатухающих колебаний дифференциальное уравнение имеет вид:
$$\ddot{x} + \omega_{0}^2 x = 0$$

где:
* $\ddot{x} = \frac{d^2x}{dt^2}$ — вторая производная координаты по времени (ускорение);
* $\omega_{0}$ — собственная циклическая частота незатухающих колебаний;
* $x$ — отклонение системы от положения равновесия.

### Формы записи решения

1. **Основная (через косинус или синус):**
   $$x(t) = a \cos(\omega_{0} t + \varphi)$$
   $$x(t) = a \sin(\omega_{0} t + \varphi)$$
2. **Линейная комбинация:**
   $$x(t) = A \sin \omega_{0} t + B \cos \omega_{0} t$$
3. **Комплексная форма (с использованием формулы Эйлера $e^{i(\omega_{0}t + \varphi)} = \cos(\omega_{0}t + \varphi) + i \sin(\omega_{0}t + \varphi)$):**
   $$x(t) = e^{i(\omega_{0} t + \varphi)}$$
   Физический смысл имеет действительная часть ($\text{Re}$) данного выражения.

### Основные характеристики колебаний

* **Амплитуда** ($a$) — максимальное отклонение системы от положения равновесия.
* **Фаза** ($\omega_{0} t + \varphi$) — аргумент гармонической функции, характеризующий состояние системы в момент времени $t$.
* **Начальная фаза** ($\varphi$) — фаза колебаний в момент времени $t = 0$.
* **Циклическая частота** ($\omega$) — скорость изменения фазы, выражающаяся как производная фазы по времени:
  $$\omega = \frac{2\pi}{T} = 2\pi\nu$$
* **Период** ($T$) — время одного полного колебания.
* **Линейная частота** ($\nu$) — количество колебаний в единицу времени ($\nu = \frac{1}{T}$), измеряется в Герцах (Гц).

## Примеры колебательных систем

### Колебания груза на пружине

Рассматривается вертикальный пружинный маятник массы $m$ и жесткости пружины $k$.

В положении равновесия сила тяжести уравновешена статической силой упругости:
$$mg - k\Delta l = 0$$

При смещении груза на величину $x$ закон движения принимает вид:
$$m\ddot{x} = mg - k(\Delta l + x) \implies m\ddot{x} = -kx$$
$$\ddot{x} + \frac{k}{m}x = 0$$

* **Собственная частота и период пружинного маятника:**
  $$\omega_{0} = \sqrt{\frac{k}{m}}, \quad T = 2\pi\sqrt{\frac{m}{k}}$$

* **Энергия системы:**
  Смещение: $x = a \cos \omega t$
  Скорость: $V_{x} = -a\omega \sin \omega t$ (амплитуда скорости $V_{xm} = a\omega$)
  Потенциальная энергия: $U = \frac{kx^2}{2} = \frac{ka^2}{2}\cos^2 \omega t$
  Кинетическая энергия: $K = \frac{mV_{x}^2}{2} = \frac{ma^2\omega^2}{2}\sin^2 \omega t$
  Полная энергия остается постоянной:
  $$E = K + U = \frac{ka^2}{2} = \text{const}$$

### Математический и физический маятники

* **Математический маятник** — точечная масса, подвешенная на легкой нерастяжимой нити длиной $l$.
* **Физический маятник** — твердое тело произвольной формы, совершающее колебания вокруг неподвижной горизонтальной оси под действием силы тяжести.

Для физического маятника уравнение моментов относительно оси вращения $Z$ записывается через векторное произведение радиус-вектора на силу тяжести $\vec{M} = [\vec{r}, m\vec{g}]$:
$$I\beta_{z} = M_{z} \implies I\ddot{\varphi} = -mgl \sin \varphi$$

Для малых углов ($\sin \varphi \approx \varphi$):
$$\ddot{\varphi} + \frac{mgl}{I}\varphi = 0$$

* **Циклическая частота физического маятника:**
  $$\omega_{0} = \sqrt{\frac{mgl}{I}}$$

где $I$ — момент инерции тела относительно оси подвеса, $l$ — расстояние от оси до центра масс $C$.

* **Приведенная длина физического маятника** ($l_{np}$) — это длина такого математического маятника, период которого совпадает с периодом данного физического маятника:
  $$l_{np} = \frac{I}{ml}$$

Для математического маятника ($I = ml^2$):
$$\omega_{0} = \sqrt{\frac{g}{l}}, \quad T = 2\pi\sqrt{\frac{l}{g}}$$

## Сложение колебаний и метод векторных диаграмм

Метод векторных диаграмм позволяет находить амплитуду и фазу результирующего колебания путем представления гармонических функций в виде векторов на плоскости.

### Алгоритм сложения колебаний

1. Все складываемые колебания приводятся к функции косинуса с помощью формул приведения:
   $$\sin(\omega t + \alpha) = \cos\left(\omega t + \alpha - \frac{\pi}{2}\right)$$
   $$-\cos(\omega t + \alpha) = \cos(\omega t + \alpha \pm \pi)$$
2. Для каждого колебания строится вектор $\vec{r}_{i} = \vec{i}\cdot a_{i}\cos\alpha_{i} + \vec{j}\cdot a_{i}\sin\alpha_{i}$, где длина вектора равна амплитуде $a_{i}$, а угол с осью $X$ равен начальной фазе $\alpha_{i}$.
3. Векторы складываются по правилу геометрии: $\vec{r} = \sum \vec{r}_{i} = \vec{i}\cdot x + \vec{j}\cdot y$.
4. Амплитуда $a$ и фаза $\alpha$ результирующего колебания рассчитываются по формулам:
   $$a = \sqrt{x^2 + y^2}, \quad \text{tg}\,\alpha = \frac{y}{x}$$

### Пример сложения

При сложении $x_{1}(t) = \sin \omega t = \cos(\omega t - \pi/2)$ и $x_{2}(t) = \cos \omega t$ с единичными амплитудами результирующий вектор имеет проекции на оси, равные единице.
$$a = \sqrt{1^2 + 1^2} = \sqrt{2}, \quad \alpha = -\frac{\pi}{4}$$
$$x_{1} + x_{2} = \sqrt{2}\cos\left(\omega t - \frac{\pi}{4}\right)$$

### Биения

Биения возникают при сложении двух колебаний с близкими частотами ($\Delta\omega \ll \omega$):
$$x_{1} = a\cos\omega t, \quad x_{2} = a\cos(\omega + \Delta\omega)t$$
$$x = x_{1} + x_{2} = 2a\cos\left(\frac{\Delta\omega}{2}t\right)\cos\omega t$$

Амплитуда результирующего колебания пульсирует с периодом биений:
$$T_{\text{б}} = \frac{2\pi}{\Delta\omega}$$

## Затухающие колебания

Затухающими называются колебания, амплитуда которых со временем уменьшается из-за сил сопротивления среды ($\vec{F}_{\text{тр}} = -r\vec{V}$).

### Уравнение затухающих колебаний
$$m\ddot{x} = -kx - r\dot{x} \implies \ddot{x} + \frac{r}{m}\dot{x} + \frac{k}{m}x = 0$$

В стандартном виде:
$$\ddot{x} + 2\beta\dot{x} + \omega_{0}^2x = 0$$

где $\beta = \frac{r}{2m}$ — коэффициент затухания, а $\omega_{0} = \sqrt{\frac{k}{m}}$ — частота системы без затухания.

### Решение уравнения
$$x(t) = a_{0}e^{-\beta t}\cos(\omega t + \alpha)$$

Частота затухающих колебаний $\omega$ всегда меньше собственной частоты $\omega_{0}$:
$$\omega = \sqrt{\omega_{0}^2 - \beta^2}$$

Период затухающих колебаний:
$$T = \frac{2\pi}{\sqrt{\omega_{0}^2 - \beta^2}}$$

### Характеристики затухания

* **Время релаксации** ($\tau$) — время, за которое амплитуда уменьшается в $e$ раз:
  $$\tau = \frac{1}{\beta}, \quad a(\tau) = a_{0}e^{-\beta\tau} = \frac{a_{0}}{e}$$
* **Логарифмический декремент затухания** ($\lambda$) — натуральный логарифм отношения амплитуд двух последовательных колебаний, разделенных периодом $T$:
  $$\lambda = \ln\frac{a(t)}{a(t+T)} = \beta T = \frac{\beta\cdot 2\pi}{\sqrt{\omega_{0}^2 - \beta^2}}$$
* **Добротность осциллятора** ($Q$) — величина, обратно пропорциональная декременту затухания:
  $$Q = \frac{\pi}{\lambda}$$

## Вынужденные колебания и резонанс

Вынужденные колебания происходят под действием внешней переменной гармонической силы $F_{x} = F_{0}\cos\omega t$.

### Уравнение вынужденных колебаний
$$m\ddot{x} + r\dot{x} + kx = F_{0}\cos\omega t \implies \ddot{x} + 2\beta\dot{x} + \omega_{0}^2x = f_{0}\cos\omega t$$

где $f_{0} = \frac{F_{0}}{m}$.

### Установившиеся колебания

После затухания собственных колебаний (по истечении времени релаксации $\tau$) система переходит в стационарный режим установившихся колебаний с частотой вынуждающей силы $\omega$:
$$x(t) = a(\omega)\cos(\omega t + \varphi)$$

С помощью метода векторных диаграмм определяются амплитуда $a(\omega)$ и сдвиг фаз $\varphi$:
$$a(\omega) = \frac{f_{0}}{\sqrt{(\omega_{0}^2 - \omega^2)^2 + 4\beta^2\omega^2}}$$
$$\text{tg}\,\varphi = \frac{2\beta\omega}{\omega_{0}^2 - \omega^2}$$

### Резонанс

>Резонанс — явление резкого возрастания амплитуды вынужденных колебаний при приближении частоты вынуждающей силы к резонансной частоте системы.

Для нахождения резонансной частоты минимизируют знаменатель функции амплитуды через производную $\frac{da}{d\omega} = 0$:
$$\omega_{\text{рез}} = \sqrt{\omega_{0}^2 - 2\beta^2}$$

Резонансная амплитуда равна:
$$a_{\text{рез}} = \frac{f_{0}}{2\beta\sqrt{\omega_{0}^2 - \beta^2}}$$

При отсутствии затухания ($\beta \to 0$) резонансная амплитуда стремится к бесконечности.

### Физический смысл добротности

При нулевой частоте ($\omega = 0$) статическое смещение равно $a_{0} = \frac{f_{0}}{\omega_{0}^2}$. В приближении слабого затухания ($\beta \ll \omega_{0}$):
$$\frac{a_{\text{рез}}}{a_{0}} \approx \frac{\omega_{0}}{2\beta} \approx \frac{\pi}{\lambda} = Q$$

**Физический смысл добротности:** $Q$ показывает, во сколько раз резонансная амплитуда больше смещения системы из положения равновесия под действием постоянной силы, равной по величине амплитуде вынуждающей силы.

## Разбор демонстрационных задач

### Задача 1. Колебания доски на вращающихся цилиндрах

Два цилиндра вращаются навстречу друг другу. Расстояние между осями равно $l$, коэффициент трения равен $K$. Доска массы $m$ смещена из центра на $x$.

Запись уравнений моментов сил относительно точек контакта дает значения сил нормальной реакции:
$$N_{1} = \frac{mg}{l}\left(\frac{l}{2} - x\right), \quad N_{2} = \frac{mg}{l}\left(\frac{l}{2} + x\right)$$

Возвращающая разность сил трения:
$$\Delta F_{\text{тр}} = F_{\text{тр}1} - F_{\text{тр}2} = K(N_{1} - N_{2}) = -\frac{2mgK}{l}x$$

Уравнение движения по второму закону Ньютона $m\ddot{x} = -\Delta F_{\text{тр}}$:
$$\ddot{x} + \frac{2gK}{l}x = 0$$

* **Частота и период системы:**
  $$\omega = \sqrt{\frac{2gK}{l}}, \quad T = 2\pi\sqrt{\frac{l}{2gK}}$$

### Задача 2. Период колебаний сложного физического маятника

Конструкция состоит из диска массы $m$ радиуса $r$ и прикрепленного к нему стержня массы $m$ длины $2r$. Маятник совершает колебания вокруг горизонтальной оси, проходящей через крайнюю верхнюю точку диска. Угол отклонения маятника от вертикали равен $\alpha$.

#### Нахождение момента инерции системы

Момент инерции маятника складывается из моментов инерции диска и стержня относительно общей оси подвеса. Для расчета применяется теорема Гюйгенса — Штейнера ($I = I_{c} + md^2$).

* **Для диска:** ось подвеса находится на расстоянии $r$ от его центра масс.
  $$I_{\text{диска}} = \frac{mr^2}{2} + mr^2 = \frac{3}{2}mr^2$$

* **Для стержня:** центр масс стержня находится посередине его длины (на расстоянии $r$ от точки скрепления с диском). Соответственно, расстояние от оси подвеса до центра масс стержня составляет $d = 2r + r = 3r$.
  $$I_{\text{стержня}} = \frac{m(2r)^2}{12} + m(3r)^2 = \frac{4mr^2}{12} + 9mr^2 = \frac{1}{3}mr^2 + 9mr^2 = \frac{28}{3}mr^2$$

* **Общий момент инерции:**
  $$I = I_{\text{диска}} + I_{\text{стержня}} = \frac{3}{2}mr^2 + \frac{28}{3}mr^2 = \frac{9 + 56}{6}mr^2 = \frac{65}{6}mr^2$$

#### Нахождение возвращающего момента сил

При отклонении маятника на малый угол $\alpha$ на каждую часть конструкции действует момент силы тяжести:

* **Момент силы тяжести диска:** плечо силы равно $r \sin \alpha \approx r\alpha$.
  $$M_{1} = mgr\alpha$$

* **Момент силы тяжести стержня:** плечо силы равно $3r \sin \alpha \approx 3r\alpha$.
  $$M_{2} = mg(3r)\alpha = 3mgr\alpha$$

* **Суммарный возвращающий момент сил:**
  $$M = M_{1} + M_{2} = mgr\alpha + 3mgr\alpha = 4mgr\alpha$$

#### Составление уравнения движения

Запишем основной закон динамики вращательного движения ($I\ddot{\alpha} = -M$):
$$\frac{65}{6}mr^2\ddot{\alpha} = -4mgr\alpha$$

Разделим обе части уравнения на $\frac{65}{6}mr^2$ и перенесем все члены в левую часть:
$$\ddot{\alpha} + \frac{4 \cdot 6}{65} \cdot \frac{g}{r}\alpha = 0$$
$$\ddot{\alpha} + \frac{24g}{65r}\alpha = 0$$

#### Ответ и характеристики колебаний

Полученное уравнение имеет стандартный вид гармонических колебаний $\ddot{\alpha} + \omega^2\alpha = 0$.

* **Циклическая частота колебаний:**
  $$\omega = \sqrt{\frac{24g}{65r}}$$

* **Период колебаний системы ($T = \frac{2\pi}{\omega}$):**
  $$T = 2\pi\sqrt{\frac{65r}{24g}}$$
