## Эллипс

>Определение: Эллипсом называется геометрическое место точек плоскости, для каждой из которых сумма расстояний до двух фиксированных точек этой плоскости, называемых фокусами, есть величина постоянная.

Фокусы обозначаются через $F_{1}$ и $F_{2}$, а постоянная сумма расстояний — через $2a$.

Пусть $|F_{1}F_{2}| = 2c$, тогда координаты фокусов: $F_{1}(-c, 0)$, $F_{2}(c, 0)$.

Для любой точки $M(x, y)$, лежащей на эллипсе, выполняется условие:
$$\rho(M, F_{1}) + \rho(M, F_{2}) = 2a$$
$$\sqrt{(x + c)^2 + y^2} + \sqrt{(x - c)^2 + y^2} = 2a$$

### Вывод канонического уравнения эллипса

Для вывода уравнения изолируем один из радикалов и возведем обе части в квадрат:
$$\sqrt{(x + c)^2 + y^2} = 2a - \sqrt{(x - c)^2 + y^2}$$
$$\left(\sqrt{(x + c)^2 + y^2}\right)^2 = \left(2a - \sqrt{(x - c)^2 + y^2}\right)^2$$
$$x^2 + 2cx + c^2 + y^2 = 4a^2 - 4a\sqrt{(x - c)^2 + y^2} + x^2 - 2cx + c^2 + y^2$$

После взаимного уничтожения одинаковых членов $x^2$, $c^2$ и $y^2$ в левой и правой частях получаем:
$$4cx = 4a^2 - 4a\sqrt{(x - c)^2 + y^2}$$

Разделим полученное выражение на 4:
$$cx = a^2 - a\sqrt{(x - c)^2 + y^2}$$

Снова изолируем радикал и возведем уравнение в квадрат:
$$a\sqrt{(x - c)^2 + y^2} = a^2 - cx$$
$$\left(a\sqrt{(x - c)^2 + y^2}\right)^2 = (a^2 - cx)^2$$
$$a^2(x^2 - 2cx + c^2 + y^2) = a^4 - 2a^2cx + c^2x^2$$
$$a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2 = a^4 - 2a^2cx + c^2x^2$$

Уничтожаем член $-2a^2cx$ в обеих частях и группируем слагаемые с переменными $x$ и $y$ слева, а константы — справа:
$$a^2x^2 + a^2y^2 - c^2x^2 = a^4 - a^2c^2$$
$$(a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)$$

По условию неравенства треугольника для фокусов и точки эллипса имеем $2a > 2c \implies a > c \implies a^2 - c^2 > 0$. Введем новое обозначение $b^2 = a^2 - c^2$. Тогда уравнение принимает вид:
$$b^2x^2 + a^2y^2 = a^2b^2$$

Разделим обе части на произведение $a^2b^2$, чтобы получить канонический вид:
>$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

Где $a$ — большая полуось, $b$ — малая полуось.

### Свойства эллипса

* Эллипс имеет две взаимно перпендикулярные оси симметрии (главные оси) и中心 симметрии (центр эллипса).
* Точки пересечения эллипса с главными осями называются его вершинами: $A_{1}(-a, 0)$, $A_{2}(a, 0)$, $B_{1}(0, -b)$, $B_{2}(0, b)$.
* Весь эллипс содержится внутри основного прямоугольника, ограниченного прямыми $x = \pm a$ и $y = \pm b$.
* При $a = b$ эллипс превращается в окружность радиуса $R = a = b$ с уравнением $x^2 + y^2 = R^2$. Фокусы при этом совпадают с центром координат ($c = 0$).
* Эксцентриситет эллипса — величина $e = \frac{c}{a}$ ($0 \le e < 1$), характеризующая степень его вытянутости (для окружности $e = 0$).

### Директрисы эллипса

Директрисами эллипса называют прямые, параллельные малой оси и отстоящие от нее на расстояние $\frac{a}{e}$. Их уравнения:
$$x = \pm \frac{a}{e}$$

**Директориальное свойство эллипса:** отношение расстояния от любой точки эллипса до его ближайшего фокуса к расстоянию от этой точки до соответствующей директрисы равно эксцентриситету эллипса:
$$\frac{M_{1}F_{1}}{M_{1}D_{1}} = \frac{M_{2}F_{2}}{M_{2}D_{2}} = e$$

## Гипербола

>Определение: Гиперболой называется геометрическое место точек плоскости, для каждой из которых абсолютная величина разности расстояний до двух фиксированных точек этой плоскости, называемых фокусами, есть величина постоянная.

Фокусы обозначаются через $F_{1}$ и $F_{2}$, а постоянная разность — через $2a$.

Пусть $|F_{1}F_{2}| = 2c$, тогда координаты фокусов: $F_{1}(-c, 0)$, $F_{2}(c, 0)$.

Для любой точки $M(x, y)$, лежащей на гиперболе, выполняется условие:
$$|\rho(M, F_{1}) - \rho(M, F_{2})| = 2a$$
$$|\sqrt{(x + c)^2 + y^2} - \sqrt{(x - c)^2 + y^2}| = 2a$$

### Каноническое уравнение гиперболы

>$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

Где $a$ — действительная полуось, $b$ — мнимая полуось. Между параметрами существует соотношение: $b^2 = c^2 - a^2$. Выводится аналогично уравнению эллипса

### Свойства гиперболы

* Гипербола имеет две оси симметрии (главные оси) и центр симметрии. Ось, пересекающая гиперболу, называется действительной осью, а непересекающая — мнимой.
* Точки пересечения гиперболы с действительной осью называются вершинами: $A_{1}(-a, 0)$, $A_{2}(a, 0)$.
* Прямоугольник со сторонами $x = \pm a$ и $y = \pm b$ называется основным прямоугольником гиперболы.
* Прямые $y = \pm \frac{b}{a}x$ являются **асимптотами** гиперболы.
* **Эксцентриситет гиперболы** — величина $e = \frac{c}{a}$ ($e > 1$).

### Доказательство асимптотического свойства прямых

Докажем, что при бесконечном удалении точки $M(x, y)$ по ветви гиперболы расстояние между ней и соответствующей точкой $M'$ на прямой $y = \frac{b}{a}x$ стремится к нулю.

Рассмотрим верхнюю половину правой ветви гиперболы, где $x \to +\infty$ и $y = \frac{b}{a}\sqrt{x^2 - a^2}$. Точка $M'$ на прямой при том же значении абсциссы $x$ имеет ординату $y' = \frac{b}{a}x$.

Расстояние между точками $M$ и $M'$ по вертикали равно:
$$\rho(M, M') = \sqrt{(x - x)^2 + \left(\frac{b}{a}x - \frac{b}{a}\sqrt{x^2 - a^2}\right)^2} = \sqrt{\left(\frac{b}{a}\right)^2 \left(x - \sqrt{x^2 - a^2}\right)^2}$$

Найдем предел этого расстояния при $x \to +\infty$, умножив и разделив выражение на сопряженное $\left(x + \sqrt{x^2 - a^2}\right)$:
$$\lim_{x \to +\infty} \rho(M, M') = \lim_{x \to +\infty} \frac{b}{a}\left(x - \sqrt{x^2 - a^2}\right) = \lim_{x \to +\infty} \frac{b}{a} \cdot \frac{\left(x - \sqrt{x^2 - a^2}\right)\left(x + \sqrt{x^2 - a^2}\right)}{x + \sqrt{x^2 - a^2}}$$
$$\lim_{x \to +\infty} \frac{b}{a} \cdot \frac{x^2 - (x^2 - a^2)}{x + \sqrt{x^2 - a^2}} = \lim_{x \to +\infty} \frac{b}{a} \cdot \frac{a^2}{x + \sqrt{x^2 - a^2}} = 0$$

Так как предел равен нулю, прямая $y = \frac{b}{a}x$ (и аналогично $y = -\frac{b}{a}x$) действительно является асимптотой кривой.

## Парабола

>Определение: Параболой называется геометрическое место точек плоскости, для каждой из которых расстояние до некоторой фиксированной точки этой плоскости, называемой фокусом, равно расстоянию до некоторой фиксированной прямой, называемой директрисой.

Фокус параболы обозначается через $F$, а директриса — через $L$.

Пусть расстояние от фокуса до директрисы равно $p$ (параметр параболы). Если расположить ось абсцисс перпендикулярно директрисе через фокус, а начало координат — посередине, то координаты фокуса равны $F\left(\frac{p}{2}, 0\right)$, а уравнение директрисы $L: x = -\frac{p}{2}$.

Для любой точки $M(x, y)$ на параболе выполняется условие $\rho(M, F) = \rho(M, L)$:
$$\sqrt{\left(x - \frac{p}{2}\right)^2 + y^2} = x + \frac{p}{2}$$

### Каноническое уравнение параболы

>$$y^2 = 2px$$

### Свойства параболы

* Парабола имеет одну ось симметрии, называемую осью параболы. Фокус расположен на этой оси.
* Точка пересечения параболы с осью симметрии называется вершиной параболы (в каноническом случае — точка $O(0,0)$).
* Если парабола ориентирована вдоль оси ординат, ее каноническое уравнение имеет вид: $x^2 = 2py$.
* **Эксцентриситет параболы** по определению равен единице ($e = 1$).

## Общее уравнение второго порядка

Алгебраическое уравнение второго порядка на плоскости в декартовой системе координат $xOy$ имеет общий вид:
>$$a_{11}x^2 + 2a_{12}xy + a_{22}y^2 + 2a_{13}x + 2a_{23}y + a_{33} = 0$$

Эллипс, гипербола и парабола являются алгебраическими линиями второго порядка. В зависимости от коэффициентов уравнение может также распадаться на пары прямых (например, $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 0 \implies y = \pm \frac{b}{a}x$) или параллельные прямые ($y^2 - a^2 = 0 \implies y = \pm a$).

## Преобразование декартовых прямоугольных координат

Пусть заданы две декартовы системы координат: старая $xOy$ и новая $x'O'y'$. Точка $M$ имеет координаты $(x, y)$ в старой системе и $(x', y')$ в новой. Если новое начало координат $O'$ имеет в старой системе координаты $(a, b)$, связь радиус-векторов выражается через базисные векторы $\vec{i}, \vec{j}$ и $\vec{i}', \vec{j}'$:
$$\overrightarrow{OM} = \overrightarrow{OO'} + \overrightarrow{O'M}$$

Разложение новых базисных векторов по старым:
$$\vec{i}' = \alpha_{11}\vec{i} + \alpha_{12}\vec{j}$$
$$\vec{j}' = \alpha_{21}\vec{i} + \alpha_{22}\vec{j}$$

Общие формулы линейного преобразования координат:
$$\begin{cases} x = a + \alpha_{11}x' + \alpha_{21}y' \\ y = b + \alpha_{12}x' + \alpha_{22}y' \end{cases}$$

### Частные случаи преобразований

1. **Параллельный перенос осей** (угол поворота $\phi = 0$):
$$\begin{cases} x = a + x' \\ y = b + y' \end{cases}$$

2. **Поворот осей на угол $\phi$** против часовой стрелки без смещения начала координат ($a = b = 0$):
Коэффициенты выражаются через тригонометрические функции направляющих косинусов: $\alpha_{11} = \cos\phi$, $\alpha_{12} = \sin\phi$, $\alpha_{21} = -\sin\phi$, $\alpha_{22} = \cos\phi$.
$$\begin{cases} x = x'\cos\phi - y'\sin\phi \\ y = x'\sin\phi + y'\cos\phi \end{cases}$$

3. **Полное преобразование** (перенос на вектор и поворот на угол $\phi$):
$$\begin{cases} x = a + x'\cos\phi - y'\sin\phi \\ y = b + x'\sin\phi + y'\cos\phi \end{cases}$$

Эти преобразования позволяют приводить общие уравнения линий второго порядка к каноническому виду для определения типа кривой.
