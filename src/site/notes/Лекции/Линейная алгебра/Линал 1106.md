## Эллипс

> **Определение**: Эллипсом называется геометрическое место точек плоскости, для каждой из которых сумма расстояний до двух фиксированных точек этой плоскости, называемых фокусами, есть величина постоянная.

Фокусы обозначаются через $F_{1}$ и $F_{2}$, а постоянная сумма расстояний — через $2a$.
Пусть расстояние между фокусами $|F_{1}F_{2}| = 2c$, тогда в прямоугольной декартовой системе координат с центром посередине отрезка $F_{1}F_{2}$ координаты фокусов имеют вид: $F_{1}(-c, 0)$, $F_{2}(c, 0)$.

Для любой точки $M(x, y)$, лежащей на эллипсе, согласно определению выполняется условие:
$$\rho(M, F_{1}) + \rho(M, F_{2}) = 2a$$
$$\sqrt{(x + c)^2 + y^2} + \sqrt{(x - c)^2 + y^2} = 2a$$

### Вывод канонического уравнения эллипса

Для вывода уравнения изолируем один из радикалов и возведем обе части в квадрат:
$$\sqrt{(x + c)^2 + y^2} = 2a - \sqrt{(x - c)^2 + y^2}$$
$$\left(\sqrt{(x + c)^2 + y^2}\right)^2 = \left(2a - \sqrt{(x - c)^2 + y^2}\right)^2$$
$$x^2 + 2cx + c^2 + y^2 = 4a^2 - 4a\sqrt{(x - c)^2 + y^2} + x^2 - 2cx + c^2 + y^2$$

После взаимного уничтожения одинаковых членов $x^2$, $c^2$ и $y^2$ в левой и правой частях получаем:
$$4cx = 4a^2 - 4a\sqrt{(x - c)^2 + y^2}$$

Разделим полученное выражение на $4$:
$$cx = a^2 - a\sqrt{(x - c)^2 + y^2}$$

Снова изолируем радикал и возведем уравнение в квадрат:
$$a\sqrt{(x - c)^2 + y^2} = a^2 - cx$$
$$\left(a\sqrt{(x - c)^2 + y^2}\right)^2 = (a^2 - cx)^2$$
$$a^2(x^2 - 2cx + c^2 + y^2) = a^4 - 2a^2cx + c^2x^2$$
$$a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2 = a^4 - 2a^2cx + c^2x^2$$

Уничтожаем член $-2a^2cx$ в обеих частях и группируем слагаемые с переменными $x$ и $y$ слева, а константы — справа:
$$a^2x^2 + a^2y^2 - c^2x^2 = a^4 - a^2c^2$$
$$(a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)$$

По условию неравенства треугольника для фокусов и произвольной точки эллипса имеем:
$$|F_{1}F_{2}| < \rho(M, F_{1}) + \rho(M, F_{2}) \implies 2c < 2a \implies a > c \implies a^2 - c^2 > 0$$

Введем новое положительное обозначение $b^2 = a^2 - c^2$. Тогда уравнение принимает вид:
$$b^2x^2 + a^2y^2 = a^2b^2$$

Разделим обе части на произведение $a^2b^2$, чтобы получить окончательный канонический вид:
>$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$

Где $a$ — большая полуось эллипса, $b$ — малая полуось эллипса.

### Свойства эллипса

* Эллипс имеет две взаимно перпендикулярные оси симметрии (главные оси) и центр симметрии (называемый центром эллипса).
* Точки пересечения эллипса с его главными осями называются вершинами эллипса: $A_{1}(-a, 0)$, $A_{2}(a, 0)$, $B_{1}(0, -b)$, $B_{2}(0, b)$.
* Весь эллипс полностью содержится внутри основного (габаритного) прямоугольника, ограниченного прямыми $x = \pm a$ и $y = \pm b$.
* В частном случае при $a = b$ эллипс вырождается в окружность радиуса $R = a = b$ с каноническим уравнением $x^2 + y^2 = R^2$. Фокусы при этом совпадают в одной точке — центре координат ($c = 0$).
* **Эксцентриситет эллипса** — величина $e = \frac{c}{a}$ ($0 \le e < 1$), характеризующая степень его вытянутости (для окружности $e = 0$).

### Директрисы эллипса

Директрисами эллипса называют прямые, параллельные малой оси и отстоящие от нее на расстояние $\frac{a}{e}$. Их канонические уравнения:
$$x = \pm \frac{a}{e}$$

**Директориальное свойство эллипса**: отношение расстояния от любой точки эллипса до его ближайшего фокуса к расстоянию от этой точки до соответствующей директрисы есть величина постоянная, равная эксцентриситету эллипса:
$$\frac{\rho(M, F_{1})}{\rho(M, D_{1})} = \frac{\rho(M, F_{2})}{\rho(M, D_{2})} = e < 1$$

## Гипербола

> **Определение**: Гиперболой называется геометрическое место точек плоскости, для каждой из которых абсолютная величина разности расстояний до двух фиксированных точек этой плоскости, называемых фокусами, есть величина постоянная.

Фокусы обозначаются через $F_{1}$ и $F_{2}$, а постоянная разность расстояний — через $2a$.
Пусть расстояние между фокусами $|F_{1}F_{2}| = 2c$, тогда в выбранной системе координат фокусы имеют координаты: $F_{1}(-c, 0)$, $F_{2}(c, 0)$.

Для любой точки $M(x, y)$, принадлежащей кривой гиперболы, выполняется условие:
$$|\rho(M, F_{1}) - \rho(M, F_{2})| = 2a$$
$$\sqrt{(x + c)^2 + y^2} - \sqrt{(x - c)^2 + y^2} = \pm 2a$$

### Вывод канонического уравнения гиперболы

Перенесем один из радикалов в правую часть выражения и возведем обе части в квадрат:
$$\sqrt{(x + c)^2 + y^2} = \pm 2a + \sqrt{(x - c)^2 + y^2}$$
$$(x + c)^2 + y^2 = 4a^2 \pm 4a\sqrt{(x - c)^2 + y^2} + (x - c)^2 + y^2$$
$$x^2 + 2cx + c^2 + y^2 = 4a^2 \pm 4a\sqrt{(x - c)^2 + y^2} + x^2 - 2cx + c^2 + y^2$$

После сокращения идентичных слагаемых получаем линейное соотношение:
$$4cx - 4a^2 = \pm 4a\sqrt{(x - c)^2 + y^2} \implies cx - a^2 = \pm a\sqrt{(x - c)^2 + y^2}$$

Повторно возводим обе части уравнения в квадрат:
$$(cx - a^2)^2 = a^2\left((x - c)^2 + y^2\right)$$
$$c^2x^2 - 2a^2cx + a^4 = a^2(x^2 - 2cx + c^2 + y^2)$$
$$c^2x^2 - 2a^2cx + a^4 = a^2x^2 - 2a^2cx + a^2c^2 + a^2y^2$$

Уничтожаем член $-2a^2cx$ и группируем переменные:
$$c^2x^2 - a^2x^2 - a^2y^2 = a^2c^2 - a^4$$
$$(c^2 - a^2)x^2 - a^2y^2 = a^2(c^2 - a^2)$$

Согласно неравенству треугольника, абсолютная разность двух сторон треугольника всегда меньше третьей стороны, то есть для фокусов и точки $M$ имеем:
$$|\rho(M, F_{1}) - \rho(M, F_{2})| < |F_{1}F_{2}| \implies 2a < 2c \implies c > a \implies c^2 - a^2 > 0$$

Введем положительный параметр $b^2 = c^2 - a^2$. Подставляя его, получаем выражение:
$$b^2x^2 - a^2y^2 = a^2b^2$$

Разделим обе части на $a^2b^2$ для получения канонического вида:
>$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$

Где $a$ — действительная полуось гиперболы, $b$ — мнимая полуось гиперболы.

### Свойства гиперболы

* Гипербола имеет две перпендикулярные оси симметрии (главные оси) и центр симметрии. Ось, проходящая через фокусы и пересекающая кривую, называется **действительной осью**, а непересекающая — **мнимой осью**.
* Точки пересечения гиперболы с действительной осью называются вершинами гиперболы: $A_{1}(-a, 0)$, $A_{2}(a, 0)$. Фокусы гиперболы всегда расположены на этой же действительной оси.
* Прямоугольник со сторонами $x = \pm a$ и $y = \pm b$ называется основным прямоугольником гиперболы.
* Прямые, содержащие диагонали основного прямоугольника, имеют уравнения $y = \pm \frac{b}{a}x$ и являются **асимптотами** гиперболы.
* **Эксцентриситет гиперболы** — величина $e = \frac{c}{a}$. Поскольку $c > a$, эксцентриситет гиперболы всегда строго больше единицы ($e > 1$).

### Доказательство асимптотического свойства прямых

Докажем, что при бесконечном удалении точки $M(x, y)$ вдоль ветви гиперболы расстояние между ней и соответствующей точкой $M'$ на прямой $y = \frac{b}{a}x$ стремится к нулю ($\lim_{x \to +\infty} \rho(M, M') = 0$).

Рассмотрим верхнюю половину правой ветви гиперболы, где $x \to +\infty$ и функция выражена как $y = \frac{b}{a}\sqrt{x^2 - a^2}$. Точка $M'$ на прямой при аналогичной абсциссе $x$ имеет ординату $y' = \frac{b}{a}x$.

Расстояние между точками $M$ и $M'$ по вертикали (перпендикуляру к оси абсцисс) равно:
$$\rho(M, M') = y' - y = \frac{b}{a}x - \frac{b}{a}\sqrt{x^2 - a^2} = \frac{b}{a} \left(x - \sqrt{x^2 - a^2}\right)$$

Найдем предел данного расстояния при $x \to +\infty$, умножив и разделив выражение на сопряженную скобку $\left(x + \sqrt{x^2 - a^2}\right)$:
$$\lim_{x \to +\infty} \rho(M, M') = \lim_{x \to +\infty} \frac{b}{a}\left(x - \sqrt{x^2 - a^2}\right) = \lim_{x \to +\infty} \frac{b}{a} \cdot \frac{\left(x - \sqrt{x^2 - a^2}\right)\left(x + \sqrt{x^2 - a^2}\right)}{x + \sqrt{x^2 - a^2}}$$
$$\lim_{x \to +\infty} \frac{b}{a} \cdot \frac{x^2 - (x^2 - a^2)}{x + \sqrt{x^2 - a^2}} = \lim_{x \to +\infty} \frac{b}{a} \cdot \frac{a^2}{x + \sqrt{x^2 - a^2}} = 0$$

Так как предел вертикального расстояния равен нулю, расстояние от точки $M$ до самой прямой (длина опущенного перпендикуляра), которое еще меньше, также стремится к нулю. Следовательно, прямая $y = \frac{b}{a}x$ (и зеркальная $y = -\frac{b}{a}x$) является асимптотой гиперболы. Утверждение доказано.

## Парабола

> **Определение**: Параболой называется геометрическое место точек плоскости, для каждой из которых расстояние до некоторой фиксированной точки этой плоскости, называемой фокусом, равно расстоянию до некоторой фиксированной прямой, называемой директрисой.

Фокус параболы традиционно обозначается через $F$, а директриса — через $L$ или $D$.
Пусть расстояние от фокуса до директрисы равно $p$ (этот параметр называют фокусным параметром параболы, $p > 0$). 

Расположим ось абсцисс перпендикулярно директрисе так, чтобы она проходила через фокус $F$, а начало координат расположим ровно посередине между фокусом и директрисой. Тогда координаты фокуса примут вид $F\left(\frac{p}{2}, 0\right)$, а уравнение директрисы примет канонический вид $L: x = -\frac{p}{2}$.

Для любой точки $M(x, y)$, лежащей на параболе, по определению расстояние до фокуса $\rho(M, F)$ должно быть равно расстоянию до директрисы $\rho(M, L)$:
$$\rho(M, F) = \sqrt{\left(x - \frac{p}{2}\right)^2 + y^2}$$
$$\rho(M, L) = \left|x - \left(-\frac{p}{2}\right)\right| = x + \frac{p}{2} \quad (\text{так как } x \ge 0)$$

Приравниваем расстояния:
$$\sqrt{\left(x - \frac{p}{2}\right)^2 + y^2} = x + \frac{p}{2}$$

### Вывод канонического уравнения параболы

Возведем обе части равенства в квадрат:
$$\left(x - \frac{p}{2}\right)^2 + y^2 = \left(x + \frac{p}{2}\right)^2$$
$$x^2 - px + \frac{p^2}{4} + y^2 = x^2 + px + \frac{p^2}{4}$$

После сокращения членов $x^2$ и $\frac{p^2}{4}$ получаем канонический вид уравнения параболы:
>$$y^2 = 2px$$

### Свойства параболы

* Парабола имеет одну фиксированную ось симметрии, называемую осью параболы. Фокус параболы всегда расположен на этой оси.
* Точка пересечения кривой параболы с ее осью симметрии называется вершиной параболы (в канонической системе координат вершина находится в начале координат $O(0,0)$).
