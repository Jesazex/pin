## Понятие уравнения линии в пространстве

Если $\Phi_{1}(x, y, z) = 0$ и $\Phi_{2}(x, y, z) = 0$ — уравнения двух поверхностей, пересечением которых является линия $L$, то система уравнений  
$$\begin{cases} \Phi_{1}(x, y, z) = 0 \\ \Phi_{2}(x, y, z) = 0 \end{cases}$$  
определяет линию $L$.

Например, система  
$$\begin{cases} y = 0 \\ z = 0 \end{cases}$$  
задает уравнение оси $Ox$.

## Уравнение прямой в общем виде

Пусть плоскости заданы общими уравнениями:  
$$\pi_{1}: A_{1}x + B_{1}y + C_{1}z + D_{1} = 0$$  
$$\pi_{2}: A_{2}x + B_{2}y + C_{2}z + D_{2} = 0$$  
причем плоскости не параллельны ($\pi_{1} \nparallel \pi_{2}$).

Тогда система уравнений  
$$\begin{cases} A_{1}x + B_{1}y + C_{1}z + D_{1} = 0 \\ A_{2}x + B_{2}y + C_{2}z + D_{2} = 0 \end{cases} \quad (1)$$  
определяет линию пересечения $\pi_{1}$ и $\pi_{2}$, то есть прямую линию. Система $(1)$ называется общим уравнением прямой как линии пересечения двух плоскостей.

Направляющий вектор $\vec{q}$ этой прямой может быть найден как векторное произведение нормальных векторов $\vec{n_{1}}$ и $\vec{n_{2}}$ заданных плоскостей:  
$$\vec{q} = [\vec{n_{1}}, \vec{n_{2}}]$$

## Канонические и параметрические уравнения прямой в пространстве

>Определение: Пусть $L$ — произвольная прямая. Любой ненулевой вектор $\vec{q}$ ($\vec{q} \neq \vec{0}$), параллельный прямой $L$, называется направляющим вектором прямой $L$.

Пусть точка $M_{0}(x_{0}, y_{0}, z_{0}) \in L$, а направляющий вектор имеет координаты $\vec{q} = \{l, m, n\}$. Тогда произвольная точка $M(x, y, z)$ принадлежит прямой $L$ тогда и только тогда, когда вектор $\vec{M_{0}M} = \{x - x_{0}, y - y_{0}, z - z_{0}\}$ коллинеарен вектору $\vec{q}$:  
$$\frac{x - x_{0}}{l} = \frac{y - y_{0}}{m} = \frac{z - z_{0}}{n} \quad (2)$$  
Уравнения $(2)$ называются каноническими уравнениями прямой в пространстве.

Если обозначить отношение в каноническом уравнении через параметр $t$:  
$$\frac{x - x_{0}}{l} = \frac{y - y_{0}}{m} = \frac{z - z_{0}}{n} = t$$  
то, выразив переменные $x$, $y$ и $z$, получим систему:  
$$\begin{cases} x = x_{0} + lt \\ y = y_{0} + mt \\ z = z_{0} + nt \end{cases} \quad (3)$$  
Уравнения $(3)$ называются параметрическими уравнениями прямой в пространстве.

## Угол между двумя прямыми в пространстве и между прямой и плоскостью

>Определение: Углом между прямыми $L_{1}$ и $L_{2}$ называется наименьший из двух углов, образуемых двумя прямыми $L'_{1}$ и $L'_{2}$, соответственно параллельными данным и проходящими через одну точку.

Пусть прямые заданы каноническими уравнениями:  
$$L_{1}: \frac{x - x_{1}}{l_{1}} = \frac{y - y_{1}}{m_{1}} = \frac{z - z_{1}}{n_{1}} \quad \text{с направляющим вектором} \quad \vec{q_{1}} = \{l_{1}, m_{1}, n_{1}\}$$  
$$L_{2}: \frac{x - x_{2}}{l_{2}} = \frac{y - y_{2}}{m_{2}} = \frac{z - z_{2}}{n_{2}} \quad \text{с направляющим вектором} \quad \vec{q_{2}} = \{l_{2}, m_{2}, n_{2}\}$$

Косинус угла между прямыми определяется через модуль косинуса угла между их направляющими векторами:  
$$\cos(L_{1}, L_{2}) = \vert{}\cos(\widehat{\vec{q_{1}}, \vec{q_{2}}})\vert{} = \frac{\vert{}l_{1}l_{2} + m_{1}m_{2} + n_{1}n_{2}\vert{}}{\sqrt{l_{1}^2 + m_{1}^2 + n_{1}^2} \cdot \sqrt{l_{2}^2 + m_{2}^2 + n_{2}^2}}$$

### Частные случаи расположения прямых в пространстве

1. Параллельность прямых ($L_{1} \parallel L_{2}$):  
    $$L_{1} \parallel L_{2} \Leftrightarrow \vec{q_{1}} \parallel \vec{q_{2}} \Leftrightarrow \frac{l_{1}}{l_{2}} = \frac{m_{1}}{m_{2}} = \frac{n_{1}}{n_{2}}$$
2. Перпендикулярность прямых ($L_{1} \perp L_{2}$):  
    $$L_{1} \perp L_{2} \Leftrightarrow \vec{q_{1}} \perp \vec{q_{2}} \Leftrightarrow l_{1}l_{2} + m_{1}m_{2} + n_{1}n_{2} = 0$$

### Условие, при котором две прямые лежат в одной плоскости

Прямые $L_{1}$ и $L_{2}$ лежат в одной плоскости $\pi$ тогда и только тогда, когда векторы $\vec{M_{1}M_{2}}$, $\vec{q_{1}}$ и $\vec{q_{2}}$ компланарны. Это означает, что их смешанное произведение равно нулю:  
$$([\vec{M_{1}M_{2}}, \vec{q_{1}}], \vec{q_{2}}) = 0 \Leftrightarrow \begin{vmatrix} x_{2} - x_{1} & y_{2} - y_{1} & z_{2} - z_{1} \\ l_{1} & m_{1} & n_{1} \\ l_{2} & m_{2} & n_{2} \end{vmatrix} = 0$$

## Угол между прямой и плоскостью

>Определение: Углом между прямой $L$ и плоскостью $\pi$ называется острый угол $\alpha$ между прямой $L$ и ее проекцией на плоскость $\pi$.

Пусть прямая задана направляющим вектором $\vec{q} = \{l, m, n\}$, а плоскость — нормальным вектором $\vec{n} = \{A, B, C\}$. Связь между искомым углом $\alpha$ и углом между векторами позволяет определить синус угла через скалярное произведение:  
$$\sin(L, \pi) = \vert{}\cos(\widehat{\vec{n}, \vec{q}})\vert{} = \frac{\vert{}Al + Bm + Cn\vert{}}{\sqrt{A^2 + B^2 + C^2} \cdot \sqrt{l^2 + m^2 + n^2}}$$

## Частные случаи расположения прямой и плоскости

1. Параллельность прямой и плоскости ($L \parallel \pi$):  
    $$L \parallel \pi \Leftrightarrow \vec{n} \perp \vec{q} \Leftrightarrow Al + Bm + Cn = 0$$
2. Перпендикулярность прямой и плоскости ($L \perp \pi$):  
    $$L \perp \pi \Leftrightarrow \vec{n} \parallel \vec{q} \Leftrightarrow \frac{A}{l} = \frac{B}{m} = \frac{C}{n}$$

## Пересечение прямой с плоскостью. Условие принадлежности прямой плоскости

Для поиска точки пересечения прямой $L$ и плоскости $\pi$ составляется система уравнений:  
$$\begin{cases} L: \frac{x - x_{0}}{l} = \frac{y - y_{0}}{m} = \frac{z - z_{0}}{n} \implies \begin{cases} x = x_{0} + lt \\ y = y_{0} + mt \\ z = z_{0} + nt \end{cases} \\ \pi: Ax + By + Cz + D = 0 \end{cases}$$

Подставляя параметрические выражения в уравнение плоскости, получаем линейное уравнение относительно параметра $t$:  
$$A(x_{0} + lt) + B(y_{0} + mt) + C(z_{0} + nt) + D = 0$$  
$$t(Al + Bm + Cn) + (Ax_{0} + By_{0} + Cz_{0} + D) = 0 \quad (*)$$

1. Если $L \nparallel \pi$, то $Al + Bm + Cn \neq 0$. Существует единственное решение для $t$:  
    $$t = -\frac{Ax_{0} + By_{0} + Cz_{0} + D}{Al + Bm + Cn}$$  
    Подстановка найденного $t$ в параметрические уравнения дает координаты точки пересечения $(x, y, z)$.
2. Если $L \parallel \pi$, то $Al + Bm + Cn = 0$.
    
    - При условии $Ax_{0} + By_{0} + Cz_{0} + D = 0$ уравнение $(*)$ принимает вид $t \cdot 0 + 0 = 0$, что верно для любого $t$. В этом случае прямая полностью лежит в плоскости ($L \subset \pi$).
    

Условие принадлежности прямой плоскости записывается в виде системы:  
$$\begin{cases} Al + Bm + Cn = 0 \\ Ax_{0} + By_{0} + Cz_{0} + D = 0 \end{cases}$$

## Расстояние от точки до прямой в пространстве

Пусть прямая задана уравнением $L: \frac{x - x_{0}}{l} = \frac{y - y_{0}}{m} = \frac{z - z_{0}}{n}$, а точка $M_{1}(x_{1}, y_{1}, z_{1}) \notin L$. Требуется найти расстояние $\rho(M_{1}, L)$.

### Способ 1

1. Составляется уравнение вспомогательной плоскости $\pi$, проходящей через $M_{1}$ перпендикулярно прямой $L$ (при этом нормальный вектор плоскости $\vec{n} = \vec{q} = \{l, m, n\}$):  
    $$l(x - x_{1}) + m(y - y_{1}) + n(z - z_{1}) = 0$$
2. Находится точка $M_{2}(x_{2}, y_{2}, z_{2})$ — точка пересечения прямой $L$ и плоскости $\pi$ путем решения совместной системы уравнений.
3. Расстояние вычисляется как длина отрезка $M_{1}M_{2}$:  
    $$\rho(M_{1}, L) = \rho(M_{1}, M_{2}) = \sqrt{(x_{2} - x_{1})^2 + (y_{2} - y_{1})^2 + (z_{2} - z_{1})^2}$$

### Способ 2

1. На прямой $L$ выбирается опорная точка $M_{0}(x_{0}, y_{0}, z_{0})$.
2. Строится параллелограмм на направляющем векторе $\vec{q}$ и векторе $\vec{M_{0}M_{1}}$.
3. Площадь параллелограмма $S$ находится через модуль векторного произведения:  
    $$S = \vert{}[\vec{q}, \vec{M_{0}M_{1}}]\vert{}, \quad \text{где} \quad [\vec{q}, \vec{M_{0}M_{1}}] = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ l & m & n \\ x_{1} - x_{0} & y_{1} - y_{0} & z_{1} - z_{0} \end{vmatrix}$$
4. Расстояние $\rho(M_{1}, L)$ представляет собой высоту параллелограмма $h = \frac{S}{a}$:  
    $$\rho(M_{1}, L) = \frac{\vert{}[\vec{q}, \vec{M_{0}M_{1}}]\vert{}}{\vert{}\vec{q}\vert{}}$$

## Расстояние между скрещивающимися прямыми

Пусть даны две скрещивающиеся прямые $L_{1}$ и $L_{2}$ с точками $M_{1}, M_{2}$ и направляющими векторами $\vec{q_{1}}, \vec{q_{2}}$ соответственно.

### Способ 1

1. Строится плоскость $\pi$, содержащая прямую $L_{1}$ и параллельная прямой $L_{2}$. Нормальный вектор плоскости находится как векторное произведение направляющих векторов:  
    $$\vec{n} = [\vec{q_{1}}, \vec{q_{2}}] = \{A, B, C\}$$
2. Составляется общее уравнение плоскости $\pi$, проходящей через точку $M_{1}(x_{1}, y_{1}, z_{1})$:  
    $$A(x - x_{1}) + B(y - y_{1}) + C(z - z_{1}) = 0 \implies Ax + By + Cz + D = 0$$
3. Расстояние между прямыми сводится к расстоянию от любой точки второй прямой (например, $M_{2}(x_{2}, y_{2}, z_{2})$) до построенной плоскости $\pi$:  
    $$\rho(L_{1}, L_{2}) = \rho(M_{2}, \pi) = \frac{\vert{}Ax_{2} + By_{2} + Cz_{2} + D\vert{}}{\sqrt{A^2 + B^2 + C^2}}$$

### Способ 2

1. На векторах $\vec{q_{1}}$, $\vec{q_{2}}$ и $\vec{M_{1}M_{2}}$ строится параллелепипед.
2. Искомое расстояние равно высоте $h$ этого параллелепипеда, опущенной на основание, образованное векторами $\vec{q_{1}}$ и $\vec{q_{2}}$.
3. Используя геометрический смысл смешанного и векторного произведений ($h = \frac{V_{\text{пар}}}{S_{\text{осн}}}$), получаем формулу:  
    $$\rho(L_{1}, L_{2}) = \frac{\vert{}([\vec{q_{1}}, \vec{q_{2}}], \vec{M_{1}M_{2}})\vert{}}{\vert{}[\vec{q_{1}}, \vec{q_{2}}]\vert{}}$$

## Примеры задач

Пример 1. Найти расстояние между скрещивающимися прямыми:  
$$L_{1}: \frac{x}{-2} = \frac{y - 1}{0} = \frac{z + 2}{1}, \quad L_{2}: \frac{x + 1}{1} = \frac{y + 1}{2} = \frac{z - 2}{-1}$$  
_Решение основано на вычислении объема параллелепипеда и площади его основания по формуле Способа 2_:  
$$\rho(L_{1}, L_{2}) = \frac{\vert{}([\vec{q_{1}}, \vec{q_{2}}], \vec{M_{1}M_{2}})\vert{}}{\vert{}[\vec{q_{1}}, \vec{q_{2}}]\vert{}}$$

Пример 2. Найти расстояние от точки $M(3, -1, 2)$ до прямой:  
$$L: \frac{x - 1}{3} = \frac{y}{-2} = \frac{z + 2}{2}$$  
_Решение выполняется через векторное произведение по формуле_:  
$$\rho(M_{1}, L) = \frac{\vert{}[\vec{q}, \vec{M_{0}M_{1}}]\vert{}}{\vert{}\vec{q}\vert{}}$$

Пример 3. Найти расстояние между параллельными прямыми на плоскости:  
$$L_{1}: y = 3x + 1, \quad L_{2}: y = 3x - 4$$  
_Для решения задачи на одной из прямых выбирается произвольная точка, после чего вычисляется расстояние от этой точки до второй прямой_.
