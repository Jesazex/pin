## Понятие уравнения линии

>Определение: Уравнение $\Phi(x, y) = 0$ называется уравнением линии $L$ относительно заданной декартовой системы координат $Oxy$, если этому уравнению удовлетворяют координаты $x$ и $y$ любой точки, лежащей на линии $L$, и не удовлетворяют координаты $x$ и $y$ ни одной точки, не лежащей на линии $L$.

>Определение: Линия $L$ называется алгебраической, если в некоторой декартовой системе координат она определяется уравнением, в котором $\Phi(x, y)$ — алгебраический полином (сумма конечного числа слагаемых вида $a_{kl}x^{k}y^{l}$, где $k, l \ge 0$ — целые числа, а $a_{kl}$ — постоянные коэффициенты). Если $\Phi(x, y)$ является полиномом порядка $n$, то линия называется алгебраической линией порядка $n$.  

_Пример:_ Окружность $(x-a)^{2} + (y-b)^{2} = R^{2}$ является алгебраической линией второго порядка.

Определение: Всякая неалгебраическая линия называется трансцендентной.

## Уравнение прямой в общем виде

Теорема: Всякое уравнение вида  
$$Ax + By + C = 0,$$  
где $A, B, C$ — действительные числа, причем $A$ и $B$ не равны нулю одновременно, определяет на плоскости прямую линию. Это уравнение называется общим уравнением прямой.

Вектор $\vec{n} = \{A, B\}$ перпендикулярен этой прямой и называется нормальным вектором прямой. Уравнение прямой, проходящей через точку $M_{0}(x_{0}, y_{0})$ перпендикулярно вектору $\vec{n} = \{A, B\}$, имеет вид:  
$$A(x - x_{0}) + B(y - y_{0}) = 0.$$

Если хотя бы один из коэффициентов $A, B, C$ равен нулю, то уравнение называется неполным. Особенности расположения прямых с неполным уравнением:

- $C = 0 \implies Ax + By = 0$ — прямая проходит через начало координат $O(0,0)$.
- $A = 0 \implies By + C = 0 \implies y = -\frac{C}{B}$ — горизонтальная прямая (параллельна оси $Ox$).
- $B = 0 \implies Ax + C = 0 \implies x = -\frac{C}{A}$ — вертикальная прямая (параллельна оси $Oy$).
- $A = 0, C = 0 \implies y = 0$ — уравнение оси абсцисс $Ox$.
- $B = 0, C = 0 \implies x = 0$ — уравнение оси ординат $Oy$.

>Теорема: Два уравнения $A_{1}x + B_{1}y + C_{1} = 0$ и $A_{2}x + B_{2}y + C_{2} = 0$ определяют одну и ту же прямую тогда и только тогда, когда их коэффициенты пропорциональны:  
$$\frac{A_{1}}{A_{2}} = \frac{B_{1}}{B_{2}} = \frac{C_{1}}{C_{2}}.$$

## Каноническое и параметрические уравнения прямой

>Определение: Любой ненулевой вектор $\vec{q}$, параллельный прямой $L$, называется её направляющим вектором. Направляющий вектор определяется неоднозначно.

Пусть зафиксирована точка на прямой $M_{0}(x_{0}, y_{0}) \in L$ и задан направляющий вектор $\vec{q} = \{l, m\}$. Для любой текущей точки прямой $M(x, y) \in L$ вектор $\overrightarrow{M_{0}M} = \{x - x_{0}, y - y_{0}\}$ коллинеарен вектору $\vec{q}$. Из условия коллинеарности получаем каноническое уравнение прямой:  
$$\frac{x - x_{0}}{l} = \frac{y - y_{0}}{m}.$$

Выразив отношения через параметр $t$, получаем параметрические уравнения прямой:  
$$\begin{cases} x = x_{0} + lt \\ y = y_{0} + mt \end{cases}$$

Частные случаи уравнений:

- Уравнение прямой, проходящей через две точки $M_{1}(x_{1}, y_{1})$ и $M_{2}(x_{2}, y_{2})$:  
    $$\frac{x - x_{1}}{x_{2} - x_{1}} = \frac{y - y_{1}}{y_{2} - y_{1}}.$$
- Уравнение прямой в отрезках (где прямая пересекает оси координат в точках $A(a, 0)$ и $B(0, b)$):  
    $$\frac{x}{a} + \frac{y}{b} = 1.$$

## Уравнение прямой с угловым коэффициентом

Пусть прямая $L$ непараллельна оси $Oy$. Углом наклона $\alpha$ прямой к оси $Ox$ называется угол между положительным направлением оси $Ox$ и прямой, отсчитываемый против часовой стрелки.

Определение: Число $k = \operatorname{tg}\alpha$ называется угловым коэффициентом прямой $L$. Если прямая параллельна $Ox$, то $k = 0$; если параллельна $Oy$, то $k$ не определен. Связь с направляющим вектором $\vec{q} = \{l, m\}$ выражается как $k = \frac{m}{l}$.

- Уравнение прямой с угловым коэффициентом:  
    $$y = kx + b,$$  
    где $b$ — ордината точки пересечения прямой с осью $Oy$.
- Уравнение прямой, проходящей через данную точку $M_{0}(x_{0}, y_{0})$ в данном направлении (уравнение пучка прямых):  
    $$y - y_{0} = k(x - x_{0}).$$

## Угол между двумя прямыми

>Определение: Углом между прямыми $L_{1}$ и $L_{2}$ называется наименьший из двух смежных углов, образованных этими прямыми.

- Если прямые заданы общими уравнениями $A_{1}x + B_{1}y + C_{1} = 0$ и $A_{2}x + B_{2}y + C_{2} = 0$, то угол между ними находится через их нормальные векторы $\vec{n_{1}}$ и $\vec{n_{2}}$:  
    $$\cos(\widehat{L_{1}, L_{2}}) = \frac{\vert{}A_{1}A_{2} + B_{1}B_{2}\vert{}}{\sqrt{A_{1}^{2} + B_{1}^{2}} \cdot \sqrt{A_{2}^{2} + B_{2}^{2}}}.$$
    
    - _Условие параллельности:_ $L_{1} \parallel L_{2} \iff \frac{A_{1}}{A_{2}} = \frac{B_{1}}{B_{2}}$.
    - _Условие перпендикулярности:_ $L_{1} \perp L_{2} \iff A_{1}A_{2} + B_{1}B_{2} = 0$.
    
- Если прямые заданы каноническими уравнениями с направляющими векторами $\vec{q_{1}} = \{l_{1}, m_{1}\}$ и $\vec{q_{2}} = \{l_{2}, m_{2}\}$:  
    $$\cos(\widehat{L_{1}, L_{2}}) = \frac{\vert{}l_{1}l_{2} + m_{1}m_{2}\vert{}}{\sqrt{l_{1}^{2} + m_{1}^{2}} \cdot \sqrt{l_{2}^{2} + m_{2}^{2}}}.$$
    
    - _Условие параллельности:_ $\frac{l_{1}}{l_{2}} = \frac{m_{1}}{m_{2}}$.
    - _Условие перпендикулярности:_ $l_{1}l_{2} + m_{1}m_{2} = 0$.
    
- Если прямые заданы уравнениями с угловым коэффициентом $y = k_{1}x + b_{1}$ и $y = k_{2}x + b_{2}$:  
    $$\operatorname{tg}(\widehat{L_{1}, L_{2}}) = \frac{\vert{}k_{2} - k_{1}\vert{}}{1 + k_{1}k_{2}}.$$
    
    - _Условие параллельности:_ $k_{1} = k_{2}$.
    - _Условие перпендикулярности:_ $1 + k_{1}k_{2} = 0 \implies k_{2} = -\frac{1}{k_{1}}$.
    

## Нормированное уравнение прямой

Пусть $\vec{n} = \{\cos\alpha, \sin\alpha\}$ — единичный вектор нормали ($\vert{}\vec{n}\vert{} = 1$), направленный из начала координат к прямой $L$, а $\alpha$ — угол между вектором $\vec{n}$ и положительным направлением оси $Ox$. Обозначим через $p$ расстояние от начала координат до прямой ($p \ge 0$).

Тогда для любой точки прямой $M(x, y)$ проекция вектора $\overrightarrow{OM}$ на направление $\vec{n}$ равна $p$, что приводит к нормированному (нормальному) уравнению прямой:  
$$x\cos\alpha + y\sin\alpha - p = 0.$$

Переход от общего уравнения к нормированному:  
Чтобы перевести уравнение $Ax + By + C = 0$ в нормированный вид, необходимо умножить его на нормирующий множитель $\lambda$:  
$$\lambda = \pm\frac{1}{\sqrt{A^{2} + B^{2}}},$$  
при этом знак $\lambda$ выбирается противоположным знаку свободного члена $C$ ($\text{знак } \lambda = -\text{знак } C$).

## Расстояние от точки до прямой

Теорема: Расстояние $\rho$ от точки $M_{0}(x_{0}, y_{0})$ до прямой $L$ равно абсолютной величине результата подстановки координат этой точки в левую часть нормированного уравнения прямой:  
$$\rho(M_{0}, L) = \vert{}x_{0}\cos\alpha + y_{0}\sin\alpha - p\vert{} = \frac{\vert{}Ax_{0} + By_{0} + C\vert{}}{\sqrt{A^{2} + B^{2}}}.$$

Пример решения задачи:  
Найти расстояние от точки $M(-1, -2)$ до прямой $3x - 4y + 5 = 0$.  
Применим формулу расстояния:  
$$\rho = \frac{\vert{}3 \cdot (-1) - 4 \cdot (-2) + 5\vert{}}{\sqrt{3^{2} + (-4)^{2}}} = \frac{\vert{}-3 + 8 + 5\vert{}}{\sqrt{9 + 16}} = \frac{10}{5} = 2.$$
